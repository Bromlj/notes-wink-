NOTES WORKSPACE · 4.1.0

Your notepad. A panel when you need it.

Write ordinary notes. Alt+W opens the Reference sidebar; Alt+S opens Notes for self. Alt+Q immediately hides both and their indicators. Replies come from your signed-in Codex account.

Getting started

Use the Notes Workspace shortcut to start the local connector and open the notepad. The browser extension needs a separately installed Codex runtime signed in with ChatGPT.

Press Alt+W, type in the question box and press Enter. Choose a model and thinking level under Options. Attach documents or drop them onto the sidebar. The current note is included only when you enable Edit this note or the first compact checkbox before sending.

Formatting buttons visibly format the note. File → Save as creates plain text; Save formatted HTML preserves the styling. Recovery saves retain formatting.

This uses your Codex allowance. Your normal ChatGPT browser remains independent; no ChatGPT webpage is opened underneath this editor.

Shortcuts

Model and thinking shortcuts work in either unlocked AI view and apply to the next request. Unsupported thinking levels leave the current choice unchanged. Shortcuts require browser/app focus; native Windows dialogs can take priority. Repeating Alt+Q never reveals AI controls.

Preferences

Optional restore passphrase

Require a passphrase when Alt+W or Alt+S reopens a hidden AI view. This prevents accidental revealing; it does not encrypt notes or secure an unlocked computer.

Notes for self

The first compact checkbox permits the next request to read and edit the current real note. The second permits its completed revision to appear automatically while compact mode is unlocked, with no newer local or disk conflict. Both start off for a new note. The first checkbox and sidebar Edit this note are the same permission; both views always agree. Turning editing off also prevents automatic compact application. Otherwise use Alt+I to append only the final answer of a completed compact reply or apply its note revision once, with Undo.

Alt+Q freezes visible AI note changes and hides the status dot; accepted disk and project work continues. Hidden automatic completion waits for Alt+S to reopen and unlock compact mode. Command and access approvals always wait for your decision in the sidebar.

Projects and Codex tools

At the top of Reference, use Project to select a saved folder or Browse folder… to choose one. Alternatively open Folder details, enter the project path and press Use folder. Codex can read and edit that project, run commands and tests, and use its configured skills and tools. Project files save directly; they do not wait for Alt+I. Additional access requests appear inside the sidebar for your decision. Returning to a previously used project can restore its conversation for this note.

An accepted task continues while hidden. Approval prompts wait for you to reopen the sidebar. Stop interrupts work. Send becomes Steer during a sidebar task so you can add instructions. Activity shows commands and file changes; Options provides saved conversations, review and context compaction.

Connection and storage

A failed request is never automatically resent. Reconnect refreshes the available models and connection.

Notes and transcripts are saved locally in the extension's browser profile. Codex keeps its own conversation history and sign-in in its user storage. The current note is included only with explicit note-edit permission. Submitted questions, attachments and content read by Codex tools use your own Codex account and tool settings. No API key is needed.

The browser extension uses the installed Codex agent runtime. Some desktop-specific interfaces, integrations and media controls are not exposed here. Text extraction supports text documents, PDFs and modern Office documents; scanned PDFs need OCR or page images. This is visual privacy, not concealment from system inspection or screen recording.
