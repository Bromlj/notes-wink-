NOTES WORKSPACE 5.3.3 — WINDOWS x64

START HERE
1. Right-click the downloaded ZIP and choose Extract All.
2. Open the extracted Notes Workspace folder and double-click Install.cmd.
3. Open the Notes Workspace desktop shortcut with the blue notepad icon.
4. Write ordinary notes immediately. For AI, follow the account steps below.

Open SETUP.html for the illustrated offline guide, or read it online:
https://github.com/Bromlj/notes-wink-/blob/main/docs/SETUP.md

No separate Node, Python, API key, Edge extension or development environment
is needed. Keep the entire extracted application folder together if you run
Notes Workspace.exe directly; its DLLs and resources are required.

CONNECT YOUR OWN ACCOUNT
Press Alt+W to open the Reference sidebar. Choose Options > Account >
Sign in with ChatGPT. Complete the official sign-in in your normal browser
using your own account, return to the app, and choose Options > Reconnect.
Select an available model and thinking level, then send a short test question.

An existing Codex sign-in for this Windows user may already work. A ChatGPT
website session alone does not sign in this app's Codex runtime. Each person
uses their own account's available Codex access and allowance. The package
contains no creator account, credentials, notes or conversations.

For project commands, check Windows project tools on the Account page.
If requested, choose Set up Windows sandbox and complete the official Windows
administrator prompt. Normal workspace restrictions and approvals remain on.

COMPACT MODE: NOTES FOR SELF
Alt+S opens a small text area with two unlabeled checkboxes and a close button.
Enter sends and closes it. Shift+Enter adds a line to the question.

The checkboxes, from left to right:
  FIRST: let the next request read and edit the current real note file.
  SECOND: automatically apply that request's completed note revision.
Both start off in every new note and are independent of sidebar Edit this note.
Turn the first on to make the second available. Settings apply before sending;
they cannot add permission to an already running request.

FIRST OFF: receive an ordinary reply. A green Ready dot means it is complete.
Press Alt+I to append the reply to the owning note once, with ordinary Undo.
Ordinary replies are never inserted automatically.

FIRST ON, SECOND OFF: Codex can edit the real note file in the background.
The displayed note stays unchanged until completion and your Alt+I shortcut.
Alt+I applies the exact revised note, not the assistant's completion message.

BOTH ON: on completion, the revised note appears automatically while compact
mode is unlocked, if no newer local or disk change conflicts. It does not
stream changes into the note while working. Automatic consent must have been
set before this request and still be enabled. Turning it off retains the
revision for manual insertion. Command and access approvals are never accepted
automatically by either checkbox.

The status dot sits after Plain text in the bottom status bar:
  GREY: working.
  GREEN / READY: a reply or revision is waiting for Alt+I.
  GREEN / DONE: a brief completion pulse, about four seconds, after automatic
  application or an automatic note task that made no change.
  AMBER: an error, conflict or approval needs attention; open Alt+W for details.

Alt+Q immediately hides the sidebar, compact box and dot and freezes visible
AI note updates. Accepted disk and project work continues. Repeated Alt+Q
presses stay hidden. If automatic work completes while hidden, it waits until
you reopen and unlock compact mode with Alt+S before updating the displayed
note. Your optional restore passphrase applies to both views.

MODELS AND THINKING
In either unlocked view, Alt+1-6 selects:
  1 Low   2 Medium   3 High   4 Extra high   5 Maximum   6 Ultra
Unsupported levels leave your current selection unchanged. Low can be useful
for simple requests; higher thinking levels can take longer.
Alt+minus / Alt+equals selects the previous / next account-provided model.
Alt+M selects the next model in either view. Use the sidebar Options button
for connection settings; Alt+M never opens those settings.
Alt+comma / Alt+period also works; Alt+Shift+M selects the next model.
The numeric title marker means model position / thinking level. For example,
3/2 means model number 3 and Medium thinking. Level 0 is a catalog default
outside the six mapped levels. Alt+W > Options shows actual model names.
Both views stay synchronized. Choices apply to the next request, not work
already running. Windows file dialogs can take keyboard focus.

FULL SIDEBAR, REAL NOTES AND PROJECTS
Alt+W opens Reference with named controls, attachments, activity and approvals.
Your text and Codex replies have distinct colours and role labels.
Edit this note above its question box enables direct note revisions, with
visible progress while the sidebar is shown. Compact editing is independent.
Alt+W can catch up a sidebar task; compact tasks use Alt+I or opted-in automatic
application after returning with Alt+S.

File > Open binds a real UTF-8 text file. Save updates it; Save As selects a
new file. Untitled notes get persistent files in local app data. The Reference
panel shows the current file path. Ordinary editing works independently of AI.

Choose Browse in the Reference sidebar to select a project folder. Codex can
read, edit, create and move real project files and run commands under normal
permissions. PROJECT CHANGES SAVE DIRECTLY; they do not need Alt+I. Attach
supported documents/images in the sidebar, or drag them onto it.
Each + tab has an independent note and chat; note-edit permissions start off.

Newer manual text, changed formatting, relinked files or newer disk edits are
protected against conflicting automatic replacement. Review the pending
revision in the sidebar. Apply pending can apply one confirmed revision while
persistent note editing is off. Undo AI edit restores an accepted revision
after completion if the note and file have not changed again. Ordinary Ctrl+Z
also works for compact insertion. Reload from disk and Relink moved file are
explicit recovery actions; the app does not recreate missing paths silently.

Hiding is a DISPLAY control. Another app opening the real file can see accepted
disk changes while this window is frozen. Use Stop in the sidebar to stop work.
Closing the whole app, sleep, crashes or connection loss can interrupt tasks.

SETTINGS, PRIVACY AND SHARING
Alt+Shift+S opens settings, the optional restore passphrase, local backup
export/import and desktop-shortcut creation.
Notes and transcripts are saved under:
%LOCALAPPDATA%\NotesWorkspace\DesktopData
Codex manages its own authentication and configuration under your user account.
Backups contain private note text and conversations. Share the original release
ZIP or repository link, never your data folder, .codex folder or backups.

The app provides visual discretion, not encryption or invisibility. Processes,
screen recording, Windows dialogs, sign-in pages and system inspection can
reveal use. A restore passphrase prevents accidental reveals; it does not
secure an unlocked computer.

The desktop shortcut, window and taskbar use a blue notepad icon. For a stale
icon, use Settings > Desktop program > Create desktop shortcut. Unpin an old
taskbar shortcut and pin the recreated shortcut if necessary. The EXE retains
the vendor Electron runtime's embedded icon and metadata; its bytes are not
resource-modified. This release has no custom signing certificate, and Windows
reputation or managed-computer policies can vary.
