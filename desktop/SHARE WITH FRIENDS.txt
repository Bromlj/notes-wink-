INSTALL AND SIGN IN
1. Download the Windows x64 ZIP, right-click it and choose Extract All.
2. Open the extracted Notes Workspace folder and run Install.cmd.
3. Open the blue Notes Workspace desktop shortcut. Ordinary notes work now.
4. Press Alt+W. Choose Options > Account > Sign in with ChatGPT.
5. Complete the official browser sign-in using YOUR OWN account, return to the
   app, and choose Options > Reconnect. Select a model and thinking level.
6. If Windows project tools requests setup, use Set up Windows sandbox and
   complete the official administrator prompt. Normal restrictions remain on.

Open the included SETUP.html for illustrated instructions and troubleshooting,
or read the same guide online:
https://github.com/Bromlj/notes-wink-/blob/main/docs/SETUP.md

No separate Node, Python, API key, Edge extension or development environment
is needed. The official Codex runtime is bundled. Each person uses their own
available Codex account access and allowance. Being signed in to ChatGPT in a
browser alone does not authenticate the app's Codex runtime.

SHORTCUTS AND THE TWO COMPACT CHECKBOXES
Alt+S opens Notes for self. Enter sends and closes it; Shift+Enter adds a line.
The first small unlabeled checkbox permits the next request to read/edit the
real current note. The second automatically applies its COMPLETED revision
while compact mode is unlocked, if no newer local or disk changes conflict.
Both start off in a new note. Turn the first on to make the second available.
Permissions must be selected before sending and cannot be added to a running
request. They are separate from the full sidebar's Edit this note setting.

With the first off, Alt+I appends an ordinary completed reply once. With the
first on and second off, Alt+I applies the exact completed note revision.
Ordinary Undo works. Ordinary replies are never inserted automatically.
The second checkbox does not stream edits or automatically accept approvals.

A dot after Plain text in the status bar is grey while working, green Ready
when manual insertion is available, and amber when attention is needed.
Green Done briefly pulses for about four seconds after automatic application,
including an automatic task that made no note change.

Alt+Q hides ALL AI controls and indicators and freezes visible AI note updates.
Accepted work on actual disk files and projects continues. A hidden automatic
completion waits until Alt+S reopens and unlocks compact mode before it appears.
Alt+W opens the full sidebar to review errors, conflicts or access approvals.
A configured restore passphrase applies to both views.

In either unlocked view, Alt+1-6 selects Low, Medium, High, Extra high, Maximum
or Ultra thinking when supported. Alt+minus / Alt+equals cycles previous / next
model. Comma/period also works; Alt+Shift+M selects the next model. The numeric
marker means model position / thinking level; 0 is another catalog default.
The sidebar shows actual names. Both views stay synchronized, and choices apply
to the next request. Shortcuts require app focus; Windows dialogs can take it.

FILES, PROJECTS AND PRIVACY
File > Open binds a real UTF-8 text file; Save updates it and Save As chooses
another file. Untitled notes get persistent document files. Each + tab has a
separate note and chat. Choose Browse in Reference to select a project folder.
Codex can edit, create and move project files and run commands under its normal
permissions. PROJECT FILES SAVE DIRECTLY; no Alt+I is needed for those changes.
Attach supported documents or images in the sidebar, or drag them onto it.

Newer local text and disk content are protected from conflicting replacement.
Review pending revisions before applying them. Undo AI edit is available after
completion if the note and file have not changed again. Another app viewing a
real file can see disk changes while this app's display is hidden. Use Stop
explicitly to stop work; closing the app can interrupt requests.

Alt+Shift+S opens settings, backups, an optional restore passphrase and desktop
shortcut creation. Recreate a stale desktop shortcut there. An old pinned
taskbar shortcut may need unpinning and re-pinning. The window, taskbar and
desktop shortcut use the blue notepad icon; the vendor EXE retains its original
embedded icon and metadata.

The interface offers visual discretion, not encryption or invisibility.
Processes, recording, system inspection and account pages can reveal use.
